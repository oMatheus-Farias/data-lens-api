## Agent skills

### Dependency installation

When implementation requires a runtime or development dependency, install it with `pnpm`, keep `pnpm-lock.yaml` in sync, and verify it through the feature's real execution path. Prefer project-managed dependencies over assuming host-level executables are installed.

### Issue tracker

Issues are tracked in GitHub Issues using `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repo. See `docs/agents/domain.md`.
